E-RAPOR SD KURIKULUM MERDEKA - VERSI WINDOWS (OFFLINE)
=====================================================

Panduan bergambar: Panduan-Admin-Sekolah.pdf (untuk admin) dan Panduan-Guru.pdf (berikan ke setiap guru)

CARA MEMASANG (SATU PAKET, DUA CARA)
1. Ekstrak ZIP: klik kanan file ZIP -> "Extract All..." (Ekstrak Semua).
2. Buka folder hasil ekstrak, klik dua kali "Pasang-E-Rapor-SD.exe"
   (jika muncul layar biru: "Info selengkapnya" -> "Tetap jalankan"),
   lalu Lanjut -> Pasang -> Selesai. Ikon "E-Rapor SD" muncul di desktop.
3. JIKA PEMASANG GAGAL: di folder yang sama, klik dua kali "Jalankan-Rapor.bat".
   Aplikasi tetap berjalan dari folder ini (langkah di bawah).

JIKA EKSTRAK ZIP BERHENTI / MUNCUL "path terlalu panjang"
Windows tidak bisa mengekstrak jalur lebih dari 260 karakter. Pindahkan file ZIP ke folder pendek, mis. C:\Rapor,
lalu Extract All di sana (bukan di dalam folder Downloads yang bersarang dalam). Tunggu sampai jendela proses tertutup sendiri.
Pastikan di folder hasil ekstrak ada: app\server.js dan node\node.exe sebelum membuka Pasang-E-Rapor-SD.exe.

JIKA WINDOWS 11 MEMBLOKIR ("Smart App Control blocked a file that may be unsafe")
Penyebab: file dari internet diberi tanda "dari internet" oleh Windows. Pemasang versi terbaru
menghapus tanda itu otomatis. Jika masih muncul, lakukan SEKALI SAJA:
1. Tekan tombol Windows, ketik "PowerShell", lalu klik "Open" (tidak perlu administrator).
2. Tempel perintah ini lalu tekan Enter:
   Get-ChildItem "$env:LOCALAPPDATA\E-Rapor-SD" -Recurse | Unblock-File
3. Buka lagi ikon E-Rapor SD di desktop.
(Jika Anda menjalankan dari folder hasil ekstrak, ganti alamat di langkah 2 dengan folder itu, mis. "D:\E-Rapor-SD".)
Alternatif tanpa memasang apa pun: buka aplikasi lewat link web yang diberikan admin (di browser).

MENJALANKAN TANPA PEMASANG (Jalankan-Rapor.bat)
1. Ekstrak (Extract All) file ZIP ini ke folder mana saja, misalnya D:\E-Rapor-SD
   (jangan dijalankan langsung dari dalam ZIP).
2. Klik dua kali "Jalankan-Rapor.bat".
3. Browser akan terbuka di http://localhost:3210
4. AKTIVASI (sekali saja): tempel Kode Aktivasi yang Anda terima saat membeli,
   lalu buat akun admin sekolah (nama pengguna & kata sandi milik sekolah sendiri).
   Kode berlaku untuk satu sekolah (sesuai NPSN) dan seumur hidup.
   Nama sekolah dan NPSN di rapor otomatis mengikuti kode aktivasi.
5. Selama memakai aplikasi, JANGAN tutup jendela hitam "E-Rapor SD".
   Untuk berhenti, tutup jendela hitam tersebut.

Tidak perlu internet dan tidak perlu menginstal apa pun.

DI MANA DATA DISIMPAN?
Semua data ada di folder "data" (file rapor.sqlite) di samping file ini.
- Cadangkan: salin folder "data" ke flashdisk, atau pakai menu "Unduh Cadangan DB".
- Pindah komputer: salin seluruh folder E-Rapor-SD (termasuk folder "data").
- Memperbarui aplikasi: ganti folder "app" dan "node" dengan versi baru,
  folder "data" JANGAN dihapus.

MEMBAGIKAN APLIKASI KE GURU (oleh admin sekolah)
Setelah logo, profil, kelas, siswa, TP, dan akun guru diatur, buka menu
"Paket Data & Bagikan ke Guru" -> pilih guru -> "Unduh aplikasi (ZIP)".
Kirim ZIP itu ke guru. Guru cukup ekstrak, jalankan Jalankan-Rapor.bat, dan login dengan
username & kata sandi yang dibuat admin. Tanpa kode aktivasi; pengaturan sekolah terkunci.
Guru mengirim hasil nilai lewat menu "Kirim Data ke Admin".

BERBAGI DATA DENGAN OPERATOR / GURU LAIN
Menu "Paket Data (ekspor/impor)":
- Operator mengekspor "Paket awal" (profil sekolah, mapel, TP) untuk guru.
- Guru mengimpor paket awal, mengisi nilai, lalu mengekspor "Data kelas lengkap".
- Operator mengimpor file dari guru untuk arsip / leger sekolah.
File paket bisa dikirim lewat flashdisk, WhatsApp, atau e-mail.

DIBUKA DARI HP / LAPTOP LAIN (OPSIONAL)
Pakai "Jalankan-Rapor-Jaringan.bat". Alamat untuk HP akan tertulis di jendela hitam,
misalnya http://192.168.1.10:3210 (HP harus tersambung ke WiFi yang sama).

MASALAH UMUM
- "Port sudah dipakai": aplikasi sudah berjalan di jendela lain. Tutup jendela itu dulu.
- Browser tidak terbuka otomatis: buka sendiri http://localhost:3210
- Windows SmartScreen memblokir: klik "More info" lalu "Run anyway".
