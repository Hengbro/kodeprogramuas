E-RAPOR SD KURIKULUM MERDEKA - PEMASANG WINDOWS
================================================

ISI FOLDER INI
- Pasang-E-Rapor-SD.exe     : pemasang aplikasi (klik dua kali)
- Panduan-Admin-Sekolah.pdf : panduan untuk admin/operator sekolah
- Panduan-Guru.pdf          : panduan untuk guru (cetak/kirim ke setiap guru)

CARA MEMASANG
1. Klik dua kali Pasang-E-Rapor-SD.exe
2. Jika muncul layar biru "Windows melindungi PC Anda":
   klik "Info selengkapnya" lalu "Tetap jalankan".
3. Klik Lanjut -> Pasang -> Selesai.
4. Ikon "E-Rapor SD" muncul di desktop. Klik dua kali untuk membuka.
5. Pertama kali: tempel Kode Aktivasi, lalu buat akun admin sekolah.

JIKA PEMASANG GAGAL (diblokir antivirus, dsb.)
Pakai file cadangan "E-Rapor-SD-Windows.zip":
klik kanan -> Extract All -> buka folder hasilnya -> klik dua kali Jalankan-Rapor.bat.
Langkahnya ada di Panduan-Admin-Sekolah.pdf, Bab 2, Cara B.
